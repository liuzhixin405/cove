# 0017 编辑结果显示改了哪几行

- 状态：已完成
- 日期：2026-11-20（创建）；2026-11-20（完成）
- 关联：[0015](0015-readme-rewrite.md)、[0016](0016-show-package-module-edits.md)（录制 README 演示时发现）

## 背景

重录 README 演示时，cove 修 bug 的编辑虽然显示出来了，但只有一行英文。

## 现状与问题

edit 的结果在界面上只显示工具输出的第一行（`app/render.rs` 的 `summary`）：

```text
● 编辑 order_service/pricing.py
  └ Edited order_service/pricing.py: 1 replacement(s)… #3
```

- 看不到改了什么：要看具体改动，得 `/expand 3` 或 `/diff`；
- 界面其他地方都是中文，这一行是英文。

工具调用的参数里本来就有改动前后的文字（`old` / `new`），用来显示一小段 diff 正好。Claude Code 显示编辑也是这样做的。

## 目标

每次编辑下面直接显示改动的几行：删掉的标红、加上的标绿；结果行改成中文。

## 方案

- 新增 `render::edit_preview(input)`：取 `old`、`new`，去掉首尾相同的行，剩下的显示为 `- 旧行`（红）和 `+ 新行`（绿）。
  - 最多显示 8 行；超出时显示前 6 行，再加一行"…… 共 +N −M 行"；
  - 每行按显示宽度截到 100 列；
  - 参数名也接受 `old_string` / `new_string`。
- 编辑成功时，在 `└` 结果行上方打印这几行。编辑失败时不打印，失败原因照旧显示。
- 结果行：`Edited <file>: N replacement(s)…` 改为"改了 N 处"。
- 只影响交互界面；`-p` 和管道输出的机器可读行不变。

## 影响范围

`src/app/render.rs`、`src/app/ui.rs`。

## 验证

- 单元测试：
  - 只显示变化的行；
  - 超长时截断并给出总数；
  - 参数缺失时不显示；
  - 结果行是"改了 N 处"。
- 全量 `cargo test`。重录演示时目视检查。

## 遗留

- 只去掉首尾相同的行，中间夹着不变行的改动会把不变行也算进 `-`/`+`。编辑通常很短，暂不做逐行 diff。
- `write` 新建文件仍只显示一行结果。
